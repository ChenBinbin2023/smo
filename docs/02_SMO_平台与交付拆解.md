## 二、详细功能拆解

### 2.1 知识图谱构建

#### 功能：临床试验领域知识图谱

**平台提供**:

**P1. 图谱引擎（OntoLogic核心）**
- 同正帆P13，复用

**P2. 本体建模工具**
- 同正帆P12，复用

**P3. 实体对齐引擎**
- **能力描述**: 自动识别和合并相同实体
- **具体功能**:
  - 中心名称标准化（"北京协和医院" = "协和医院" = "PUMCH"）
  - 研究者姓名对齐（处理不同写法）
  - 疾病名称对齐（ICD编码映射）
  - 相似度计算（编辑距离、拼音、语义相似度）
  - 对齐建议与人工确认
- **提供形式**: 对齐引擎 + 确认界面
- **配置能力**: 配置对齐规则、相似度阈值

**交付完成**:

**D1. 临床试验领域本体建模**
- **工作内容**:
  - 设计中心实体本体（属性：名称、等级、床位数、GCP证书、科室设置等）
  - 设计研究者实体本体（属性：姓名、职称、科室、执业年限等）
  - 设计试验实体本体（属性：试验编号、适应症、分期、样本量等）
  - 设计疾病本体（基于ICD-10，建立层级结构）
  - 设计药物本体（基于ATC分类）
  - 定义实体间关系（参与、擅长、相似等）
- **交付物**: 临床试验领域本体模型（OWL文件）
- **工作量**: 7-10人日（领域较复杂，需要医学知识）

**D2. 知识图谱数据导入**
- **工作内容**:
  - 从药物临床试验登记平台采集31,336个试验数据
  - 从客户CRM系统采集1,400个中心信息
  - 从EDC系统采集历史入组数据
  - 数据清洗与标准化（中心名称、研究者姓名统一）
  - 实体对齐（合并重复实体）
  - 导入图谱引擎
  - 建立实体间关系（试验-中心、试验-研究者、中心-研究者等）
- **交付物**: 包含31,336试验、1,400中心、23,000研究者的知识图谱
- **工作量**: 10-15人日（数据量大，清洗工作量大）

**D3. 医学本体集成**
- **工作内容**:
  - 集成ICD-10疾病分类体系
  - 集成ATC药物分类体系
  - 建立疾病与适应症的映射关系
  - 建立药物与治疗方案的关联
- **交付物**: 医学本体数据
- **工作量**: 3-5人日

### 2.2 智能检索

#### 功能：语义化搜索

**平台提供**:

**P4. 语义搜索引擎**
- **能力描述**: 支持自然语言搜索
- **具体功能**:
  - NLU意图识别（搜索中心、搜索研究者、搜索试验）
  - 实体识别（疾病名称、地理位置、试验分期等）
  - 本体扩展（"肺癌"→"非小细胞肺癌"、"小细胞肺癌"）
  - 混合检索（关键词+向量+图谱）
  - 结果排序与解释
- **提供形式**: 搜索服务 + API
- **配置能力**: 配置领域词典、排序策略

**P5. 向量检索引擎**
- **能力描述**: 基于向量相似度的语义检索
- **具体功能**:
  - 文本向量化（BERT/Sentence-BERT）
  - 向量索引（Faiss/Milvus）
  - 快速向量检索（毫秒级）
  - 向量召回与重排序
- **提供形式**: 向量数据库 + API
- **配置能力**: 选择向量化模型、配置索引参数

**交付完成**:

**D4. 临床试验领域词典构建**
- **工作内容**:
  - 收集临床试验领域专业术语
  - 建立同义词词典（"肺癌" = "肺部肿瘤" = "Lung Cancer"）
  - 建立缩写词典（"GCP" = "Good Clinical Practice"）
  - 建立实体识别训练数据
- **交付物**: 领域词典、NER训练数据
- **工作量**: 3-5人日

**D5. 中心/研究者向量化**
- **工作内容**:
  - 为每个中心生成描述文本（基于历史试验、能力标签）
  - 为每个研究者生成描述文本
  - 使用BERT模型向量化
  - 构建向量索引
- **交付物**: 中心向量库、研究者向量库
- **工作量**: 2-3人日

**D6. 搜索效果优化**
- **工作内容**:
  - 收集用户搜索日志
  - 标注搜索意图和期望结果
  - 优化排序模型（LTR）
  - 调整排序权重
- **交付物**: 优化后的搜索模型
- **工作量**: 3-5人日（上线后持续优化）

#### 功能：相似案例检索

**平台提供**:

**P6. 相似度计算引擎**
- **能力描述**: 计算试验-试验、中心-项目的相似度
- **具体功能**:
  - 多模态特征提取（文本、结构化、图结构）
  - 相似度算法库（余弦、欧式、Jaccard）
  - 加权组合
  - 相似度解释（哪些特征相似）
- **提供形式**: 相似度服务 + API
- **配置能力**: 配置特征权重、相似度算法

**交付完成**:

**D7. 试验相似度特征定义**
- **工作内容**:
  - 定义试验相似度的关键特征（适应症、分期、设计类型、样本量、入排标准）
  - 设计特征向量化方法
  - 设置特征权重（如适应症权重0.4、分期权重0.3等）
  - 测试相似度计算效果
- **交付物**: 特征定义、权重配置
- **工作量**: 3-4人日

**D8. 中心-项目匹配度模型**
- **工作内容**:
  - 定义中心与项目的匹配度计算逻辑
  - 考虑维度：能力匹配、地理位置、成本、历史表现
  - 训练匹配度模型（基于历史数据：哪些中心-项目组合成功率高）
  - 验证模型效果
- **交付物**: 匹配度模型
- **工作量**: 5-7人日

### 2.3 智能分析

#### 功能：能力画像生成

**平台提供**:

**P7. 指标计算引擎**
- 同正帆P11，复用

**P8. 标签管理平台**
- 同正帆P7，复用

**P9. 画像可视化组件**
- **能力描述**: 丰富的画像展示组件
- **具体功能**:
  - 指标卡片（KPI展示）
  - 雷达图（多维能力展示）
  - 时间序列图（趋势展示）
  - 热力图（分布展示）
  - 标签云（标签展示）
- **提供形式**: 前端组件库
- **配置能力**: 通过Props配置数据和样式

**交付完成**:

**D9. 中心能力指标体系设计**
- **工作内容**:
  - 定义中心能力指标（历史业绩类、资质类、协作类）
  - 历史业绩指标：入组速度、完成率、方案偏离率、受试者留存率
  - 资质指标：GCP证书、伦理委员会等级、床位数、科室完善度
  - 协作指标：沟通响应速度、文档质量、CRC配置
  - 设计指标计算公式（如入组速度 = 总入组人数 / 试验执行月数）
  - 设置指标权重
- **交付物**: 指标定义文档、计算公式配置
- **工作量**: 5-7人日

**D10. 中心能力标签体系设计**
- **工作内容**:
  - 设计能力标签（擅长适应症、擅长试验分期、受试者画像）
  - 设计风险标签（合规风险、能力风险、协作风险）
  - 配置标签打标规则（基于历史数据统计）
  - 示例："中心参与肺癌试验5次且成功率>80% → 擅长肺癌"
- **交付物**: 标签体系、打标规则
- **工作量**: 4-5人日

**D11. 研究者画像体系设计**
- **工作内容**:
  - 定义研究者能力指标
  - 设计研究者标签
  - 配置计算和打标规则
- **交付物**: 研究者画像体系
- **工作量**: 3-4人日

**D12. 画像仪表盘开发**
- **工作内容**:
  - 设计中心画像仪表盘布局
  - 使用画像可视化组件开发界面
  - 绑定后端API
  - 实现交互（下钻、对比等）
- **交付物**: 画像仪表盘页面
- **工作量**: 5-7人日

**P10. 规则引擎**

**P11. 异常检测框架**
- **能力描述**: 识别指标异常
- **具体功能**:
  - 基于阈值的检测
  - 基于统计的检测（3-sigma、MAD）

- **交付物**: 风险规则库

**D14. 风险监控配置**
- **工作内容**:
  - 配置风险监控指标
  - 设置监控频率（实时、每日、每周）
  - 配置风险预警阈值
  - 配置预警通知方式（邮件、短信、系统消息）
- **交付物**: 监控配置
- **工作量**: 2-3人日

## 七、总结

### 7.1 平台能力显著增强

SMO项目在正帆项目的基础上，新增了14项平台能力：
- **检索能力**: 语义搜索、向量检索、相似度计算
- **分析能力**: 画像可视化、异常检测、对比分析、推荐引擎
- **预测能力**: 时序预测框架、模型训练平台
- **协同能力**: 决策追溯、任务管理、Agent编排、Prompt管理

这些新增能力有**10项具有高复用价值**，将大大增强平台的通用性。

### 7.2 交付工作量合理

- **交付工作量**: 128-179人日
- **项目周期**: 5个月（6人团队）
- **效率提升**: 55-65%（相比无平台情况）

相比正帆项目（82-119人日），SMO项目工作量增加约50%，主要原因：
- 数据源更多更复杂（5个系统 vs 3个系统）
- 数据量更大（31,336试验 vs 百万级交易）
- 需要训练预测模型（新增工作量）
- 需要开发Agent（新增工作量）

但考虑到业务价值和平台能力的提升，投入是合理的。

### 7.3 业务价值巨大

- **效率**: 决策时间从2-3周缩短到2-3天（10x）
- **质量**: 中心选择准确率从63%提升到85%
- **成本**: 减少22%的中心选择错误，节省大量试验成本
- **规模化**: 支持更多项目并行开展，业务规模化扩张

### 7.4 下一步建议

1. **优先开发新增的高复用能力**: P3-P6（检索相关）、P11-P15（分析预测相关）、P18-P22（协同相关）
2. **建立行业方案**: 将SMO项目的配置、模型、Prompt沉淀为"临床试验行业方案"，快速复制到其他CRO/SMO客户
3. **持续优化模型**: 上线后持续收集数据，优化预测模型和推荐模型
4. **扩展到其他场景**: 基于平台能力，扩展到其他临床试验场景（如研究者选择、试验设计优化等）
