# 客户2：思睦达(SMO) - 本体视角的平台能力与交付内容拆解

## 一、拆解原则

### 1.1 本体三层架构视角

基于本体技术文档的三层架构，从以下维度拆解功能：

| 本体层级 | 核心问题 | 关键能力 | 在SMO项目的体现 |
|---------|---------|---------|-----------------|
| **Semantic（语义层）** | 世界里"有什么" | 对象+关系+状态 | 临床试验领域本体、中心、研究者、试验、疾病、药物 |
| **Kinetic（行为层）** | 世界"如何运行" | 过程+约束+可行动作 | 推荐规则、匹配度计算、风险识别、能力评估 |
| **Dynamic（决策层）** | 世界"下一步该怎么变" | 仿真+决策+调度 | 入组预测、中心组合模拟、决策追溯 |

### 1.2 本体核心要素映射

| 本体要素 | 定义 | 在SMO项目中的具体体现 |
|---------|------|---------------------|
| **对象(Object)** | 有身份、生命周期和状态的业务实体 | 中心、研究者、试验、疾病、药物、方案 |
| **链接(Link)** | 对象之间的关系，是一等公民 | 试验→中心、试验→研究者、中心→研究者、疾病→药物 |
| **规则(Rule)** | 业务判断逻辑，支持DAG编排 | 中心筛选规则、匹配度计算规则、风险识别规则 |
| **动作(Action)** | 改变系统状态的操作 | 确定试验中心、更新推荐列表、标记风险 |
| **函数(Function)** | 纯计算，不改变状态 | 计算中心能力画像、计算相似度、预测入组速度 |
| **仿真(Simulation)** | What-If场景分析与决策推演 | 中心组合模拟、入组进度预测、风险情景模拟 |

## 二、按本体三层架构的功能拆解

### 2.1 语义层（Semantic Layer）- 临床试验世界建模

语义层解决"临床试验世界里有什么"的问题，构建可查询、可追溯、可演化的临床试验对象宇宙。

**平台提供**:

**P-Onto-2. 本体元数据服务(OMS)（OntoLogic核心）** - 复用正帆

**交付完成**:

**D-Onto-1. 临床试验领域本体模型设计**
- **工作内容**:
  - **设计中心实体本体（Object Type）**:
    - 对象类型：中心（Center）
    - 属性：名称、等级（三甲/二甲）、床位数、GCP证书、科室设置、地理位置
    - 约束：名称必填、GCP证书有效期校验
    - 关系：中心→科室、中心→研究者、中心→历史试验
  - **设计研究者实体本体（Object Type）**:
    - 对象类型：研究者（Investigator）
    - 属性：姓名、职称（主任医师/副主任医师）、科室、执业年限、专长
    - 约束：姓名必填、职称必填
    - 关系：研究者→中心、研究者→历史试验、研究者→擅长疾病
  - **设计试验实体本体（Object Type）**:
    - 对象类型：试验（Trial）
    - 属性：试验编号、适应症、分期（I/II/III/IV期）、样本量、入排标准、设计类型
    - 约束：试验编号唯一
    - 关系：试验→适应症、试验→药物、试验→中心、试验→研究者
  - **设计疾病本体（Object Type）**:
    - 对象类型：疾病（Disease）
    - 属性：ICD-10编码、疾病名称、疾病分类
    - 约束：ICD-10编码唯一
    - 关系：疾病→上位疾病（层级结构）、疾病→药物（治疗关系）
  - **设计药物本体（Object Type）**:
    - 对象类型：药物（Drug）
    - 属性：ATC编码、药物名称、药物分类、作用机制
    - 约束：ATC编码唯一
    - 关系：药物→ATC分类（层级结构）、药物→疾病（适应症）
  - **建立对象间关系（Link Type）**:
    - 试验→中心（participated_by）：历史参与关系
    - 试验→研究者（led_by）：主要研究者关系
    - 中心→研究者（employs）：雇佣关系
    - 研究者→疾病（specializes_in）：擅长关系
    - 试验→疾病（targets）：适应症关系
- **交付物**: 临床试验领域本体模型（OWL文件 + UML图 + 说明文档）
- **工作量**: 7-10人日（领域较复杂，需要医学知识）
- **关键技术**: 本体建模工具、OMS

  - **集成ATC药物分类体系**:

    - 映射试验药物到ATC编码

- **工作量**: 3-5人日
- **关键技术**: 本体集成、医学知识库

  - **配置风险推理规则**:
    - 规则1: IF GCP证书有效期<3个月 THEN 标签="GCP风险"
    - 规则2: IF PI近6个月离职 THEN 标签="人员风险"
- **交付物**: 推理规则库
- **工作量**: 3-4人日
- **关键技术**: 推理引擎

### 2.2 行为层（Kinetic Layer）- 临床试验世界的运行

行为层解决"临床试验世界如何运行"的问题，定义过程、约束、可行动作。

#### 功能模块3：智能检索与匹配

**平台提供**:

**P-Onto-18. 语义搜索引擎（OntoLogic核心）**
- **能力描述**: 支持自然语言搜索
- **具体功能**:
  - **NLU意图识别**: 识别搜索意图（搜索中心、搜索研究者、搜索试验）
  - **实体识别**: 提取实体（疾病名称、地理位置、试验分期）
  - **本体扩展**: 利用本体进行查询扩展（"肺癌" → "非小细胞肺癌"、"小细胞肺癌"）
  - **混合检索**: 关键词检索 + 向量检索 + 图谱检索
  - **结果排序与解释**: 按相关性排序，解释为什么推荐这些结果
- **提供形式**: 搜索服务 + API
- **配置能力**: 配置领域词典、排序策略
- **本体三层映射**: 行为层检索能力（基于语义层对象）

**P-Onto-19. 向量检索引擎（OntoLogic核心）**
- **能力描述**: 基于向量相似度的语义检索
- **具体功能**:
  - **文本向量化**: 使用BERT/Sentence-BERT将文本转为向量
  - **向量索引**: 使用Faiss/Milvus构建向量索引
  - **快速向量检索**: 毫秒级检索（在百万级向量中检索）
  - **向量召回与重排序**: 先召回Top-100，再根据其他特征重排序
- **提供形式**: 向量数据库 + API
- **配置能力**: 选择向量化模型、配置索引参数
- **本体三层映射**: 行为层检索能力

**P-Onto-20. 相似度计算引擎（OntoLogic核心）**
- **能力描述**: 计算对象间的相似度
- **具体功能**:
  - **多模态特征提取**: 文本特征、结构化特征、图结构特征
  - **相似度算法库**: 余弦相似度、欧式距离、Jaccard相似度
  - **加权组合**: 多特征加权计算综合相似度
  - **相似度解释**: 解释哪些特征相似（如"适应症相同"、"分期相同"）
- **提供形式**: 相似度服务 + API
- **配置能力**: 配置特征权重、相似度算法
- **本体三层映射**: 行为层计算能力

**交付完成**:

**D-Onto-8. 临床试验领域词典构建**
- **工作内容**:
  - **收集专业术语**:
    - 疾病术语（从ICD-10、试验数据中提取）
    - 药物术语（从ATC、试验数据中提取）
    - 试验术语（分期、设计类型、入排标准）
  - **建立同义词词典**:
    - 示例："肺癌" = "肺部肿瘤" = "Lung Cancer"
    - 示例:"GCP" = "Good Clinical Practice" = "药物临床试验质量管理规范"
  - **建立缩写词典**:
    - 示例: "NSCLC" = "非小细胞肺癌"
  - **建立实体识别训练数据**:
    - 标注疾病实体、药物实体、机构实体
    - 训练NER模型
- **交付物**: 领域词典、NER训练数据、NER模型
- **工作量**: 3-5人日
- **关键技术**: NLU、实体识别

**D-Onto-9. 中心/研究者向量化**
- **工作内容**:
  - **生成中心描述文本**:
    - 基于中心属性（名称、等级、科室）
    - 基于历史试验（参与过的适应症、试验类型）
    - 基于能力标签（擅长肺癌、入组能力强）
    - 拼接成描述文本
  - **向量化中心**:
    - 使用BERT模型向量化描述文本
    - 生成中心向量（768维）
    - 存入向量数据库
  - **生成研究者描述文本**:
    - 基于研究者属性（姓名、职称、科室、专长）
    - 基于历史试验
    - 拼接成描述文本
  - **向量化研究者**:
    - 使用BERT模型向量化
    - 存入向量数据库
  - **构建向量索引**:
    - 使用Faiss构建HNSW索引
    - 优化检索速度
- **交付物**: 中心向量库（1,400个向量）、研究者向量库（23,000个向量）
- **工作量**: 2-3人日
- **关键技术**: BERT、向量检索引擎

**D-Onto-10. 试验相似度计算配置**
- **工作内容**:
  - **定义试验相似度特征**:
    - 特征1: 适应症相似度（基于ICD层级距离）
    - 特征2: 分期相似度（I/II/III/IV期编码距离）
    - 特征3: 设计类型相似度（随机对照/单臂等）
    - 特征4: 样本量相似度（归一化后的欧式距离）
    - 特征5: 入排标准文本相似度（向量余弦相似度）
  - **设置特征权重**:
    - 适应症权重=0.4（最重要）
    - 分期权重=0.3
    - 设计类型权重=0.15
    - 样本量权重=0.1
    - 入排标准权重=0.05
  - **配置相似度计算**:
    - 综合相似度 = Σ(特征相似度 × 权重)
  - **测试相似度计算**:
    - 选择代表性试验对
    - 计算相似度
    - 人工评估相似度是否合理
    - 调整权重
- **交付物**: 试验相似度配置
- **工作量**: 3-4人日
- **关键技术**: 相似度计算引擎

**D-Onto-11. 中心-项目匹配度模型开发**
- **工作内容**:
  - **定义匹配度维度**:
    - 能力匹配：中心是否擅长该适应症
    - 资质匹配：中心是否有GCP证书、伦理委员会
    - 经验匹配：中心是否有相似试验经验
    - 地理位置：中心是否在目标区域
    - 成本：中心的成本是否在预算内
